The Problem

Ad Blockers Win

uBlock Origin and Brave block 30-40% of your analytics. You're making business decisions with incomplete data.

DNS Conflicts

Setting up reverse proxies with platforms like Webflow and Namecheap means wrestling with CNAME/A-Record conflicts.

Hidden Costs

Traditional proxy solutions require always-on servers. That means monthly bills even when traffic is zero.

How It Works

nginx.conf 
# Reverse proxy for PostHog analytics
server {
    listen 8080;
    server_name api.yourdomain.com;

    location /ingest/ {
        proxy_pass https://us.i.posthog.com/;
        proxy_set_header Host us.i.posthog.com;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For 
                         $proxy_add_x_forwarded_for;
        proxy_ssl_server_name on;
    }

    location /static/ {
        proxy_pass https://us-assets.i.posthog.com/static/;
        proxy_set_header Host us-assets.i.posthog.com;
        proxy_ssl_server_name on;
    }
}
posthog.init() 
// Initialize with your custom proxy endpoint
posthog.init('phc_YOUR_PROJECT_KEY', {
    // Route through YOUR domain, not posthog.com
    api_host: 'https://api.yourdomain.com/ingest',
    
    // UI stays on PostHog for dashboards
    ui_host: 'https://us.posthog.com',
    
    // Always create person profiles
    person_profiles: 'always',
});

// That's it. Events now bypass ad blockers.
